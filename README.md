# Таксопарк

Консольний додаток на Java для лабораторної роботи з ООП. Моделює парк таксі:
ієрархію легкових автомобілів (седан, хетчбек, позашляховик, мінівен), підрахунок
вартості автопарку, сортування за витратою палива та пошук авто за діапазоном
максимальної швидкості.

## Структура пакетів

- `com.dagen.taxifleet.model` — ієрархія `PassengerCar` та її підкласи
- `com.dagen.taxifleet.data` — завантаження даних автопарку з файлу
- `com.dagen.taxifleet.service` — логіка `TaxiPark` (вартість, сортування, пошук)
- `com.dagen.taxifleet.app` — консольне меню

Початковий склад автопарку зберігається в `data/fleet.txt` і завантажується при
старті програми.

## Збірка та запуск

```
mvn package
java -jar target/taxi-fleet-lab.jar
```

Запускати потрібно з кореня репозиторію, бо `data/fleet.txt` читається за
відносним шляхом.

## Тести

```
mvn test
```

Юніт-тести написані на JUnit 5, для сервісного шару використано Mockito.
